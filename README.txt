FRITZ TRAINER — SITE INSTITUCIONAL
==================================

TECNOLOGIAS
- HTML5
- CSS3
- JavaScript puro

COMO ABRIR
1. Extraia a pasta do ZIP.
2. Abra a pasta "fritz-trainer-site" no VS Code.
3. Abra o arquivo index.html no navegador.
   (Opcional: use a extensão Live Server no VS Code.)

ANTES DE PUBLICAR
Este é o primeiro front-end funcional do site institucional. Alguns dados reais ainda precisam ser inseridos:
- endereço e cidade;
- telefone e WhatsApp oficiais;
- horários de funcionamento;
- modalidades realmente oferecidas;
- planos, valores e condições;
- fotos reais da estrutura, equipamentos e equipe;
- links oficiais de Instagram e outras redes.

IMPORTANTE SOBRE O FORMULÁRIO
O formulário valida os campos no navegador, mas ainda não envia nem armazena dados. Para receber contatos, conecte-o a um endpoint seguro, serviço de formulários ou backend. Não coloque credenciais privadas no JavaScript público.

IMAGENS
A logo enviada foi incluída em assets/logo-fritz-trainer.png. As duas fotos de academia usadas no layout são imagens remotas de demonstração; substitua-as por fotos autorizadas da própria FRITZ TRAINER antes de publicar.

PERSONALIZAÇÃO
- Cores principais estão em :root no início de css/style.css.
- Fotos estão nos seletores .hero-photo e .feature-image.
- Conteúdo e seções ficam em index.html.
